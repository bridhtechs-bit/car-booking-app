   ├─ Email: user@example.com\n        └─ Password: {hashed_password}\n    ↓\nBackend Validates\n    ├─ Check user exists\n    ├─ Verify password with bcrypt\n    └─ Generate JWT token\n    ↓\nResponse: { _id, email, name, role, token }\n    ↓\nFrontend stores:\n    ├─ localStorage.adminToken = token\n    └─ localStorage.user = { id, email, name, role, token }\n    ↓\nSubsequent Requests\n    ├─ API Interceptor gets token\n    ├─ Adds header: Authorization: Bearer {token}\n    └─ Backend validates token\n    ↓\nOn Token Expiration\n    ├─ Backend returns 401\n    ├─ Response Interceptor detects 401\n    ├─ Clears localStorage\n    └─ Redirects to /login\n```\n\n---\n\n## Quick Start Guide\n\n### Start Backend\n\n```bash\ncd webApp/node\nnpm install\nnpm start\n# Server
